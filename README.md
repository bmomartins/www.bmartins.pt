# Bruno Martins personal website

This repository contains the source for Bruno Martins' personal website, hosted at `bmartins.pt`.

It is a static, lightweight web presence designed to act as a digital profile and contact point. The site presents Bruno's professional background, social links, certifications, community involvement, and personal interests, while also offering a contact form for people who want to reach out.

## What the site includes

- a home page with links to social, professional, and contact channels
- an about page describing his career, skills, certifications, and values
- a contact page with a form and spam protection
- dark mode support and basic localization behavior
- a Netlify serverless function that validates submissions and sends the message using an email service

## Tech stack

- plain HTML, CSS, and JavaScript
- Tailwind CSS for styling
- Netlify Functions for the contact backend
- hCaptcha for bot protection
- Resend for outbound email delivery

## Purpose

This is not a large application project; it is a personal portfolio and profile site. The goal is to make Bruno easy to find online, highlight his technology and infrastructure expertise, and provide a simple, secure way to get in touch.
